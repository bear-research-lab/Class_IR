# Part 1: 정기구학 (Forward Kinematics)

*[English](PART1_FK.md)*

RB5는 6개의 관절 각도로 움직입니다. 정기구학(FK)은 "이 관절 각도에서 핸드는 어디에 있고 어느
방향을 향하는가?"에 답합니다. 이 파트에서는 RB5의 FK를 두 번 작성합니다. 한 번은 직접 유도하고,
한 번은 실무에서처럼 MuJoCo 함수를 써서 구합니다. 그리고 관절 각도 파일을 재생하면서 두 결과를
시뮬레이터와 비교해 확인합니다.

## 1. 구현할 것

### 1.1 직접 유도한 FK

**`student_kinematics.py`**의 `forward_kinematics()`를 채우세요.

```python
def forward_kinematics(q, tool=np.eye(4)) -> T   # 베이스 좌표계에서 본 툴 좌표계의 4x4 자세
```

| 인자 | 의미 |
|---|---|
| `q` | (6,) 관절 각도 [rad]: base, shoulder, elbow, wrist1, wrist2, wrist3 |
| `tool` | (4, 4) 플랜지 좌표계에서 본 툴 좌표계의 자세. 단위행렬이면 플랜지 자체입니다. 로봇은 여기에 핸드의 `grasp` 사이트를 넘겨줍니다 (기본 핸드: 플랜지 z축 방향으로 90 mm) |
| 반환값 `T` | (4, 4) 동차 변환행렬 T_base_tool = T_base_flange(q) · tool |

NumPy만 사용하세요. 이 파일에서 `mujoco`나 `rb5_sim`을 import하면 안 됩니다 (스크립트가 검사합니다).
로봇은 이 함수로 움직이며, 기구학을 직접 유도하는 것이 이 함수의 목적입니다.

### 1.2 MuJoCo로 구하는 FK

**`student_mujoco.py`**의 `mujoco_fk()`를 채우세요.

```python
def mujoco_fk(model, data, q, site="tcp") -> T   # MuJoCo로 구한 사이트의 4x4 자세
```

| 인자 | 의미 |
|---|---|
| `model`, `data` | 시뮬레이션의 `MjModel`과 여러분 전용 `MjData` (바꿔도 로봇은 움직이지 않습니다) |
| `q` | (6,) 관절 각도 [rad], 위와 같은 순서 |
| `site` | `"tcp"` = 플랜지, `"grasp"` = 핸드의 grasp 사이트 |
| 반환값 `T` | (4, 4) 베이스 좌표계에서 본 사이트의 자세 |

이 파일에서는 MuJoCo와 NumPy를 씁니다 (`rb5_sim`은 안 됩니다). 필요한 것은 `qpos`에서 관절의
위치(`model.joint(name).qposadr`), `mujoco.mj_kinematics`, 그리고 `data.site_xpos`와
`data.site_xmat`에 있는 사이트 자세입니다. 모델에는 손가락과 피펫도 들어 있어서 팔 관절이 단순히
`qpos[0:6]`이 아닙니다. 함수 목록과 간단한 설명은 파일 맨 위에 있습니다.

## 2. 로봇

형상은 `assets/rb5_850e/rb5_850e.xml`에서 가져온 것입니다. 각 링크 좌표계는 부모 좌표계를
오프셋만큼 이동한 뒤, 관절 축(이동한 좌표계 기준)을 중심으로 관절 각도만큼 회전한 것입니다.
q = 0이면 모든 링크 좌표계가 평행합니다.

| 관절 | 이전 좌표계로부터의 오프셋 [m] | 축 |
|---|---|---|
| 1 base | (0, 0, 0.1692) | z |
| 2 shoulder | (0, 0, 0) | y |
| 3 elbow | (0, 0, 0.425) | y |
| 4 wrist1 | (0, 0, 0.392) | y |
| 5 wrist2 | (0, −0.1107, 0.1107) | z |
| 6 wrist3 | (0, 0, 0) | y |
| 플랜지 | (0, −0.0967, 0) 이동 후 x축으로 +90° 회전 | - |

플랜지 좌표계의 z축은 플랜지 바깥쪽을 향합니다. q = 0이면 팔이 똑바로 위를 향합니다.

이 변환들을 그대로 곱해도 되고, 여기서 Denavit–Hartenberg 표를 유도해도 됩니다. 어느 쪽이든
괜찮고, 선택한 방법을 보고서에 설명하세요. 확인용 값:

| q [deg] | 플랜지 위치 [m] | 플랜지 회전행렬 |
|---|---|---|
| (0, 0, 0, 0, 0, 0) | (0, −0.2074, 1.0969) | [[1, 0, 0], [0, 0, −1], [0, 1, 0]] |
| (90, 0, 90, 0, 0, 0) | (0.2074, 0.5027, 0.5942) | [[0, 0, 1], [0, 1, 0], [−1, 0, 0]] |

## 3. 관절 각도 파일

관절 각도 파일은 관절 각도의 시계열입니다. 한 줄에 경유점 하나를 `key:value` 쌍으로 씁니다.

```
# 주석
T:0  theta1:31.27 theta2:-28.19 theta3:130.43 theta4:77.76 theta5:-58.73 theta6:90
T:2  theta1:0     theta2:-28.19 theta3:130.43 theta4:77.76 theta5:-58.73 theta6:90
```

- `T`: 로봇이 그 줄에 도달하는 시각 [s]이며, 줄마다 증가해야 합니다. 첫 줄은 로봇의 시작 자세입니다.
- `theta1` … `theta6`: 관절 각도, 단위는 **도(degree)**.

로봇은 줄 사이를 부드럽게 이동합니다. 예시는 `trajectories/joints_example.txt`에 있습니다.

## 4. 테스트

```
uv run part1_fk.py                                          # 채점용 테스트
uv run part1_fk.py trajectories/joints_example.txt          # 뷰어에서 관절 각도 파일 재생
uv run part1_fk.py trajectories/joints_example.txt --out my_poses.txt   # FK 결과 자세를 파일로 저장
```

- **채점용 테스트** (파일 없이 실행): 경우마다 무작위 관절 각도 100개에서, `forward_kinematics()`는
  플랜지, 기본 핸드의 grasp 사이트, 무작위 툴 좌표계에 대해, `mujoco_fk()`는 `tcp`와 `grasp`
  사이트에 대해 시뮬레이터와 비교합니다. 위치 오차가 0.001 mm, 회전 오차가 1e-6 rad 이내이면
  통과입니다. 항목마다 따로 결과를 내므로 (아직 안 했으면 "not implemented yet") 어느 쪽부터
  해도 됩니다.
- **파일 재생**: 뷰어에 **여러분의** FK로 계산한 grasp 사이트 좌표계(긴 축: x 빨강, y 초록, z 파랑)와
  그 궤적이 그려집니다. FK가 맞다면 이 좌표계가 핸드의 두 손가락 사이에 붙어 있습니다. 경유점마다
  여러분의 FK 위치, 시뮬레이터의 위치, 그 오차가 출력됩니다.
- `--out`은 FK 결과를 자세 파일로 저장합니다. 이 파일은 Part 2의 입력 형식입니다.
